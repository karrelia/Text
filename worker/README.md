# Voice2Text UA на Cloudflare Workers

Той самий бот, що й у корені репозиторію, але без сервера: код виконується
на Cloudflare, безкоштовно й безстроково. Нічого не треба орендувати,
оновлювати чи перезапускати.

Розгортання займає хвилин десять і робиться один раз.

---

## Що знадобиться

| Що | Де взяти | Платно? |
| --- | --- | --- |
| Токен бота | [@BotFather](https://t.me/BotFather) → `/newbot` | ні |
| Ключ OpenRouter | [openrouter.ai/keys](https://openrouter.ai/keys) | поповнення від $5 |
| Ключ Groq | [console.groq.com](https://console.groq.com/keys) | є безкоштовний ліміт |
| Акаунт Cloudflare | [dash.cloudflare.com/sign-up](https://dash.cloudflare.com/sign-up) | ні, картка не потрібна |

Замість Groq можна взяти [OpenAI](https://platform.openai.com/api-keys) —
трохи стабільніша якість, але дорожче.

Ще потрібен [Node.js](https://nodejs.org) на вашому комп'ютері. Він потрібен
лише щоб один раз залити код; далі бот працює без вашої участі.

## Розгортання

### 1. Завантажити код

```bash
git clone https://github.com/karrelia/Text.git
cd Text/worker
npm install
```

### 2. Увійти в Cloudflare

```bash
npx wrangler login
```

Відкриється браузер — підтвердіть доступ.

### 3. Створити сховище налаштувань

```bash
npx wrangler kv namespace create SETTINGS
```

Команда виведе рядок із `id = "..."`. Скопіюйте цей id у `wrangler.toml`
замість `ЗАМІНИТИ_НА_ID_З_КОМАНДИ_WRANGLER`.

### 4. Записати секрети

Кожна команда спитає значення й приховає його при введенні:

```bash
npx wrangler secret put TELEGRAM_BOT_TOKEN
npx wrangler secret put OPENROUTER_API_KEY
npx wrangler secret put GROQ_API_KEY
npx wrangler secret put WEBHOOK_SECRET
```

`WEBHOOK_SECRET` вигадайте самі — довільний довгий рядок. Він потрібен, щоб
чужі запити не могли прикинутись Telegram.

### 5. Залити

```bash
npx wrangler deploy
```

У відповідь буде адреса виду `https://voice2text-ua.ваш-акаунт.workers.dev`.

### 6. Прив'язати вебхук

Відкрийте в браузері (підставте свою адресу й свій `WEBHOOK_SECRET`):

```
https://voice2text-ua.ваш-акаунт.workers.dev/setup?secret=ВАШ_WEBHOOK_SECRET
```

Має з'явитись «Вебхук прив'язано». Це разова дія.

### 7. Відкрити собі доступ

Бот приватний і поки не пускає нікого, зокрема вас.

1. Напишіть боту `/start` — він відповість відмовою і покаже ваш Telegram ID.
2. Запишіть цей ID секретом (кілька людей — через кому):

```bash
npx wrangler secret put ALLOWED_USER_IDS
```

Готово, повторний `deploy` не потрібен. Напишіть `/start` — бот привітається.

Список дозволених саме секрет, а не змінна в `wrangler.toml`: так він не
лежить у git і не зникає при оновленні коду.

### Переробити тим самим записом

Під кожною розшифровкою й кожним зчитаним знімком є кнопки, які проганяють
**той самий** запис ще раз — надсилати голосове чи фото повторно не треба.

| Кнопка | Що робить |
| --- | --- |
| 🔁 Інша модель | перелік моделей; вибір одразу переробляє запис |
| ✍️ Інший стиль | те саме для режиму обробки (Чистовик, Діловий, промт для відео…) |
| 💬 Вказівка | разова вимога до цього результату — див. нижче |
| 🎧 Перерозпізнати | заново завантажує аудіо і розпізнає його з нуля |

Модель і стиль із переліку заразом стають новими типовими значеннями —
окремо йти в `/model` чи `/style` не потрібно.

**Вказівка** — це прохання саме до цього результату: «а тепер списком», «а
промт хай буде українською». Кнопка дає готові варіанти (Списком, Стисло,
Детальніше, Українською, Англійською; для фото — Списком, Лише числа,
Таблицею, Лише рукописне) і окремо «Своя вказівка»: після неї напишіть
своїми словами, що змінити, і бот перепише той самий запис.

Вказівка головніша за правила подачі: саме вона визначає формат, обсяг і
мову відповіді, інакше «зроби списком» розбивалося б об вимогу суцільного
тексту, а «англійською» — об заборону перекладати. Недоторканим лишається
те, заради чого режим існує: у розшифровці — точність чисел, імен і фактів,
у генерації — названий вами задум, а на фото — вірність зчитаного.

На відміну від моделі та стилю, вказівка **не осідає в налаштуваннях**: вона
живе разом із записом і на наступному голосовому не спливе. Показується під
результатом, щоб не забути, що саме зараз застосовано; наступні кнопки її
зберігають, тож «списком» плюс «інша модель» дадуть список іншою моделлю.

Єдиний виняток — стиль «Без обробки»: він взагалі не звертається до моделі,
тож виконати вказівку не може. На такий прогін бот бере найближчий за духом
«Дослівно» — лексика автора так само лишається його.

Зміна моделі чи стилю **не розпізнає аудіо вдруге**: сирий текст із Whisper
лишається в KV на добу, і переробка бере його звідти. Це і швидше, і не
списує гроші за те саме розпізнавання. Кнопка «Перерозпізнати» — саме на
випадок, коли треба інакше почути: після зміни рушія (`/stt`) чи поповнення
словника (`/glossary`).

Для знімка стилі не пропонуються — там свій промт читача; модель береться
окрема (`/vision`), а решту задає вказівка.

Під результатом видно, у скільки він обійшовся: вартість цього виклику й
підсумок за добу («0.04¢ · сьогодні 1.20¢»). Різниця між дешевою та дорогою
моделлю на одному записі — десятки разів, і помітити її варто до того, як
вона перетвориться на рахунок за місяць. Дрібні суми показуються в центах,
бо «$0.0004» не читається. Розпізнавання через Groq сюди не входить — у
нього своя тарифікація й окремий безкоштовний ліміт. Якщо OpenRouter
вартості не повернув, підпису просто не буде.

Перелік після вибору сам зникає з чату, щоб не лишати за собою мертвих
кнопок. Якщо відповідь не вмістилась в одне повідомлення Telegram, поруч
приходить той самий текст файлом `.txt` — скопіювати його цілим одним
дотиком простіше, ніж виділяти через межі бульбашок.

Запис зберігається під рукою добу. Далі кнопки чесно скажуть, що
переробляти вже нічого — файл у Telegram лишається, але прибирати з KV
безстроково нема сенсу.

Перелік команд у меню «/» бот публікує сам: після `deploy` він порівнює
збережений зліпок із тим, що в коді, і за розбіжності перевидає меню на
першому ж вашому повідомленні. Окремо відкривати `/setup` для цього не
треба — він потрібен лише один раз, для прив'язки вебхука.

### Фото → текст

Надішліть знімок документа, накладної чи показників лічильника — бот зчитає
з нього текст і подасть його читабельно на телефоні.

Бланки й акти, де більшість полів порожні, виводяться вертикально —
«Назва поля: значення», по одному в рядок, порожні поля пропускаються.
Роздільник `|` лишається тільки для справді щільних таблиць. Дописане від
руки виноситься в окремий розділ наприкінці, а не всередину клітинок.

**Багатосторінковий документ.** Надішліть сторінки одним альбомом — бот
дочекається їх усіх і прочитає як один документ: спільна шапка виводиться
раз, таблиця, розірвана між знімками, склеюється. Telegram шле кожне фото
альбому окремим оновленням, тож бот збирає їх у KV і чекає півтори секунди
(`ALBUM_WAIT_MS` у `wrangler.toml`). За раз читається до десяти сторінок.

**Підпис під фото стає вказівкою.** Надішліть знімок із підписом «лише
показники» або «зроби таблицю» — бот зробить саме це. Без підпису просто
зчитує весь текст.

Нерозбірливі місця позначаються як `[нерозбірливо]` — модель не здогадується
за вас, що особливо важливо на числах і сумах.

Модель для фото окрема від текстової (`/vision`), бо не всі моделі приймають
зображення — у списку показані лише ті, що приймають.

**Таблицею для Excel.** Під зчитаним текстом є друга кнопка, яка переносить його
в CSV і надсилає файлом. Роздільник — крапка з комою, на початку файлу BOM:
саме так Excel з українськими налаштуваннями відкриває його готовою
таблицею з кирилицею, а не суцільним рядком і кракозябрами.

### Нагадування

```
/remind у вівторок о 9 здати звіт
/remind через дві години передзвонити Кириленку
```

**Команда взагалі не обов'язкова.** Скажіть або напишіть «нагадай завтра о 9
здати звіт» — бот сам зрозуміє намір і поставить нагадування. Достатньо
слова «нагадай», «нагадування», «напомни» чи «не забудь» будь-де у фразі,
зокрема в кінці надиктованого: «26 серпня, 8:30, виконком, нагадування».

Розпізнавання наміру — проста перевірка за словами, без звернення до
моделі: вона виконується на кожному повідомленні, і зайвий виклик LLM
коштував би грошей та секунди затримки на кожній розшифровці. Якщо слово
є, а часу у фразі немає, бот мовчки лишає звичайну розшифровку — не сварить
за нотатку зі словом «нагадування».

Під створеним нагадуванням є кнопка «Прибрати» — на випадок, якщо бот
зрозумів не так. Вимкнути самостійні нагадування зовсім — `/autoremind`.

У списку `/reminders` записи показані текстом повністю, а прибирають їх
окремі кнопки з номерами: раніше кнопкою був сам рядок, і дотик, щоб
роздивитися обрізаний текст, знищував нагадування. Прибране повертає
кнопка «↩️ Повернути» протягом п'яти хвилин.

Час розбирає модель зі звичайної фрази. Команда `/remind` теж лишається:
без тексту вона бере щойно розшифроване, а як відповідь на повідомлення —
текст із нього.

**Повторювані.** Інтервал довільний: «щомісяця 29 числа о 9 передати
показники», «щотижня», «щогодини», «кожні три хвилини», «раз на два тижні».
Після кожного спрацювання запис сам ставить наступне.

Хвилини й години рахуються як проміжки реального часу, а доба й довші — як
настінний час: «щодня о 9:00» лишається о 9:00 і після переходу на зимовий,
хоча доба тоді триває 25 годин. Якщо потрібного числа в місяці немає, воно
підтягується до останнього дня: «щомісяця 31-го» у лютому стане 28-м, а не
поїде на березень.

**Коли не вийшло.** На пряме прохання («нагадай…», «додай нагадування…»)
бот скаже, що не зрозумів, і підкаже, як переформулювати. Якщо ж слово
«нагадування» просто трапилось посеред нотатки, він мовчки лишить звичайну
розшифровку — сварити за нотатку не варто.

**Коли прийшло невчасно.** Під нагадуванням, що спрацювало, є «+1 год»,
«+3 год», «Завтра» і «✅ Готово». Відкладене — окремий одноразовий запис:
якщо нагадування повторюване, серія від цього не збивається, наступне
спрацювання за розкладом лишається на місці. Відкласти можна протягом доби.

Раз на хвилину Worker прокидається за розкладом (Cron Trigger) і надсилає
те, чому настав час. Список — `/reminders`, там же кнопкою прибрати зайве.

Часовий пояс задається у `wrangler.toml` (`TIMEZONE`, типово `Europe/Kyiv`).
Перехід на літній час враховується автоматично — зсув береться на конкретну
дату, а не фіксовано.

### Протокол наради

Стиль «📋 Протокол» (`/style`) робить із надиктованої наради не суцільний
текст, а структуру, за якою можна діяти:

```
ОБГОВОРЮВАЛИ
— стан мереж по вулиці Озерна

ВИРІШИЛИ
— замінити ділянку до кінця місяця

ДОРУЧЕННЯ
— Кірпосенко — передати показники — до 20.08
— Кириленко — підготувати акт — термін не названо

ЦИФРИ Й ФАКТИ
— 40538909 — номер лічильника на Озерній
```

Під протоколом є кнопка «⏰ Нагадування з доручень»: вона ставить
нагадування на кожне доручення, у якого названо термін. Доручення без дати
пропускаються мовчки — вигадати дату означало б розсипати по календарю
зобов'язання, яких ніхто не брав.

Це окремий вид завдання, а не ще один стиль редактора: редактору прямо
заборонено переказувати («це редагування, а не переказ»), а протокол — саме
переказ, тільки строго за фактами. Тому в нього власний базовий промпт і
нульова температура: вигадане прізвище чи число тут не косметична вада, а
помилка, за якою хтось діятиме.

Звичайне розпізнавання прохань нагадати в цьому режимі вимкнене — інакше
слово «нагадати» посеред наради створювало б випадкове нагадування замість
справжніх доручень.

### Шаблони документів

Свій бланк плюс надиктовані обставини — і документ готовий. Спершу заведіть
бланк: перший рядок після команди — назва, решта — сам бланк.

```
/template акт
АКТ обстеження вузла обліку
Дата:
Адреса:
Лічильник №
Показання:
Пломба:
Висновок:
```

Далі надиктуйте обставини звичайним голосовим — і натисніть **📄 За
шаблоном** під розшифровкою. Бот поверне той самий бланк, заповнений тим,
що прозвучало.

Чого в записі не було, позначається `[не вказано]` — порожнє місце в
документі гірше за чесну позначку: за ним не видно, чи забули заповнити,
чи даних справді не було. Структура й формулювання бланка лишаються
недоторканими: бот його заповнює, а не переписує. Якщо в записі є істотне,
чого бланк не передбачає, воно йде окремим рядком «Додатково:» наприкінці,
а не втискається в чужі поля.

Кнопка працює і після знімка: сфотографували паперовий акт — бот зчитав
текст — і той самий бланк заповнюється зчитаним. Заповнений документ лягає
під кнопку «📊 Таблицею для Excel», тож звідти його можна одразу вивантажити.

| Команда | Що робить |
| --- | --- |
| `/template` | перелік бланків |
| `/template акт` | показати бланк |
| `/template акт` + бланк з нового рядка | зберегти або замінити |
| `/template - акт` | прибрати |

До двадцяти бланків, кожен до 4000 символів: бланк щоразу їде в запиті до
моделі, тож має лишатися бланком, а не книжкою. Назва має бути короткою —
з неї робиться ідентифікатор для кнопки, а там усього 64 байти, і кирилиця
важить удвічі.

Кнопка «📄 За шаблоном» з'являється тільки тоді, коли бланки справді є —
інакше вона щоразу відкривала б порожній перелік.

### Пошук по надиктованому

Записи зберігаються три місяці. `/history` показує останні, `/find слово` —
шукає:

```
/find Гаркушенці показники
```

Слова шукаються за коренем, тож відмінки не заважають: «Гаркушенц» знайде і
«Гаркушенцях», і «Гаркушенці». Кілька слів звужують пошук — потрібні всі.
Знайдене показується переліком з датами, кнопка з номером розгортає запис
повністю. Знімки теж потрапляють в історію й шукаються нарівні з голосовими.

Влаштовано це так, щоб пошук не читав усі записи поспіль. У KV немає ані
повнотекстового пошуку, ані запиту за вмістом — значення дістаються лише
по одному, і сотня читань на кожен пошук була б і повільною, і марною. Тому
слова кладуться **в ключ**: `list()` віддає імена одним викликом, фільтрувати
по них можна без жодного читання, а самі записи дістаються тільки для тих
кількох, що збіглися.

Ціна рішення — ключ обмежений 512 байтами, тож у покажчик потрапляє близько
сотні різних слів запису. Для нотатки це весь текст, для години наради —
початок: знайти за словом із середини довгого запису не вийде.

Повторний прогін тим самим записом переписує ту саму позицію, а не додає
нову — інакше після трьох спроб із різними моделями пошук показував би три
майже однакові рядки замість одного.

### Три режими

**Розшифровка** записує сказане охайно й нічого не додає — це типова
поведінка.

**Генерація** робить протилежне: розгортає надиктовану ідею в готовий промт,
свідомо дописуючи те, чого ви не називали — освітлення, пору доби, план і
рух камери, настрій, фактури.

> «потрібен промт для відео, де дівчина йде красивим містом»
> → сцена з ранковим світлом, бруківкою, повільним рухом камери слідом,
> конкретними деталями одягу й настрою.

Промти для відео та зображень пишуться англійською — генеративні моделі
розуміють її значно краще. Для одного промта мову міняє кнопка «💬 Вказівка»
під результатом, назавжди — команда `/prompt` (наприклад: `/prompt пиши
промти українською`).

Названий вами задум — герой, дія, місце — лишається недоторканим: модель
додає деталі, але не підміняє суть.

Налаштування зберігаються окремо для кожного користувача в Cloudflare KV.
Поля, яких ви не змінювали, підхоплюють значення з `wrangler.toml` — тобто
нову типову модель достатньо прописати в конфізі й зробити `deploy`.

## Обмеження цього варіанта

Порівняно з Python-версією в корені репозиторію:

- **Розпізнавання лише через Whisper** (Groq чи OpenAI). Аудіо-моделі
  OpenRouter недоступні: вони приймають mp3 і wav, Telegram віддає ogg, а
  перекодувати нема чим — ffmpeg у Workers не запускається. Вибір
  **текстової** моделі через OpenRouter лишається повним.
- **Довгі записи не ріжуться на шматки** — з тієї ж причини. На практиці це
  майже не заважає: Telegram і так не дає ботам завантажувати файли більші
  за 20 МБ, а голосове в opus важить близько 1 МБ за 10 хвилин.
- **Фото й нагадування є лише тут.** Python-версія їх не має: нагадування
  потребують планувальника, якого в ній немає, і переносити його туди сенсу
  мало, поки бот працює на Cloudflare.
- **Дедуплікація не абсолютна.** Якщо обробка затягнеться, Telegram надішле
  оновлення повторно; від подвійної обробки захищає позначка в KV, але KV
  синхронізується між регіонами не миттєво, тож рідкісний подвійний запуск
  теоретично можливий.

## Обслуговування

Подивитись, що відбувається в реальному часі:

```bash
npx wrangler tail
```

Оновити код після змін — знову `npx wrangler deploy`.

Ліміти безкоштовного тарифу, у які ми вкладаємось: 100 000 запитів на добу,
10 мс процесорного часу на запит (очікування мережі не рахується), 128 МБ
пам'яті. Тривалість запиту не обмежена, поки Telegram тримає з'єднання —
саме тому обробка йде синхронно, а не через `waitUntil()`, який обірвався б
через 30 секунд.

## Розробка

```bash
npm test          # модульні тести
npm run typecheck # перевірка типів
npm run dev       # локальний запуск на workerd
```

Для локального запуску створіть файл `.dev.vars` (він у `.gitignore`):

```
TELEGRAM_BOT_TOKEN=...
OPENROUTER_API_KEY=...
GROQ_API_KEY=...
WEBHOOK_SECRET=...
ALLOWED_USER_IDS=...
```

Структура:

```
src/
├── index.ts            маршрути, перевірка секрету, дедуплікація, планувальник
├── env.ts              змінні оточення та рушії STT
├── telegram.ts         клієнт Bot API, розбір повідомлень
├── settings.ts         персональні налаштування в KV
├── prompts.ts          промпти редактора, стилі обробки
├── texts.ts            тексти інтерфейсу, розбиття довгих відповідей
├── keyboards.ts        інлайн-клавіатури
├── openrouter.ts       редагування тексту, каталог моделей
├── stt.ts              розпізнавання через Whisper
├── vision.ts           читання тексту з фото
├── album.ts            збирання альбому знімків в один документ
├── history.ts          історія записів і пошук по них
├── templates.ts        бланки документів і їх заповнення
├── reminders.ts        розбір, зберігання та вибірка нагадувань
├── recurrence.ts       обчислення наступного спрацювання повторів
├── timezone.ts         локальний час користувача з урахуванням переходів
├── pipeline.ts         сценарії «голосове → текст» і «фото → текст»
└── handlers/
    ├── commands.ts     обробка команд
    └── callbacks.ts    обробка натискань на кнопки
```
