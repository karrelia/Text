# Voice2Text UA на Cloudflare Workers

Той самий бот, що й у корені репозиторію, але без сервера: код виконується
на Cloudflare, безкоштовно й безстроково. Нічого не треба орендувати,
оновлювати чи перезапускати.

Розгортання займає хвилин десять і робиться один раз.

---

## Що знадобиться

| Що | Де взяти | Платно? |
| --- | --- | --- |
| Токен бота | [@BotFather](https://t.me/BotFather) → `/newbot` | ні |
| Ключ OpenRouter | [openrouter.ai/keys](https://openrouter.ai/keys) | поповнення від $5 |
| Ключ Groq | [console.groq.com](https://console.groq.com/keys) | є безкоштовний ліміт |
| Акаунт Cloudflare | [dash.cloudflare.com/sign-up](https://dash.cloudflare.com/sign-up) | ні, картка не потрібна |

Замість Groq можна взяти [OpenAI](https://platform.openai.com/api-keys) —
трохи стабільніша якість, але дорожче.

Ще потрібен [Node.js](https://nodejs.org) на вашому комп'ютері. Він потрібен
лише щоб один раз залити код; далі бот працює без вашої участі.

## Розгортання

### 1. Завантажити код

```bash
git clone https://github.com/karrelia/Text.git
cd Text/worker
npm install
```

### 2. Увійти в Cloudflare

```bash
npx wrangler login
```

Відкриється браузер — підтвердіть доступ.

### 3. Створити сховище налаштувань

```bash
npx wrangler kv namespace create SETTINGS
```

Команда виведе рядок із `id = "..."`. Скопіюйте цей id у `wrangler.toml`
замість `ЗАМІНИТИ_НА_ID_З_КОМАНДИ_WRANGLER`.

### 4. Записати секрети

Кожна команда спитає значення й приховає його при введенні:

```bash
npx wrangler secret put TELEGRAM_BOT_TOKEN
npx wrangler secret put OPENROUTER_API_KEY
npx wrangler secret put GROQ_API_KEY
npx wrangler secret put WEBHOOK_SECRET
```

`WEBHOOK_SECRET` вигадайте самі — довільний довгий рядок. Він потрібен, щоб
чужі запити не могли прикинутись Telegram.

### 5. Залити

```bash
npx wrangler deploy
```

У відповідь буде адреса виду `https://voice2text-ua.ваш-акаунт.workers.dev`.

### 6. Прив'язати вебхук

Відкрийте в браузері (підставте свою адресу й свій `WEBHOOK_SECRET`):

```
https://voice2text-ua.ваш-акаунт.workers.dev/setup?secret=ВАШ_WEBHOOK_SECRET
```

Має з'явитись «Вебхук прив'язано». Це разова дія.

### 7. Відкрити собі доступ

Бот приватний і поки не пускає нікого, зокрема вас.

1. Напишіть боту `/start` — він відповість відмовою і покаже ваш Telegram ID.
2. Впишіть цей ID у `wrangler.toml`:

```toml
ALLOWED_USER_IDS = "123456789"
```

3. Залийте ще раз:

```bash
npx wrangler deploy
```

Готово. Напишіть `/start` — бот привітається.

## Команди бота

| Команда | Що робить |
| --- | --- |
| `/settings` | показує поточну конфігурацію |
| `/model` | модель редагування — пресети, пошук (`/model claude`) або точний id |
| `/style` | режим: розшифровка (Чистовик / Дослівно / Діловий / Без обробки) або генерація промтів (відео / зображення / розгорнути ідею) |
| `/stt` | рушій розпізнавання: Groq або OpenAI |
| `/vision` | модель для читання фото |
| `/remind` | створити нагадування |
| `/reminders` | список нагадувань, кнопкою — прибрати |
| `/glossary` | імена, назви й терміни, які треба писати правильно |
| `/prompt` | власна інструкція на додачу до стандартних правил |
| `/reset` | скинути все до типових значень |

### Фото → текст

Надішліть знімок документа, накладної чи показників лічильника — бот зчитає
з нього текст, зберігаючи структуру: рядки лишаються рядками, таблиці
оформлюються через `|`.

**Підпис під фото стає вказівкою.** Надішліть знімок із підписом «лише
показники» або «зроби таблицю» — бот зробить саме це. Без підпису просто
зчитує весь текст.

Нерозбірливі місця позначаються як `[нерозбірливо]` — модель не здогадується
за вас, що особливо важливо на числах і сумах.

Модель для фото окрема від текстової (`/vision`), бо не всі моделі приймають
зображення — у списку показані лише ті, що приймають.

### Нагадування

```
/remind у вівторок о 9 здати звіт
/remind через дві години передзвонити Кириленку
```

Час розбирає модель зі звичайної фрази.

Щойно надиктували голосове — просто надішліть `/remind` без тексту, бот
візьме щойно розшифроване. Якщо треба взяти саме конкретне повідомлення —
відповідайте командою на нього.

Раз на хвилину Worker прокидається за розкладом (Cron Trigger) і надсилає
те, чому настав час. Список — `/reminders`, там же кнопкою прибрати зайве.

Часовий пояс задається у `wrangler.toml` (`TIMEZONE`, типово `Europe/Kyiv`).
Перехід на літній час враховується автоматично — зсув береться на конкретну
дату, а не фіксовано.

### Два режими

**Розшифровка** записує сказане охайно й нічого не додає — це типова
поведінка.

**Генерація** робить протилежне: розгортає надиктовану ідею в готовий промт,
свідомо дописуючи те, чого ви не називали — освітлення, пору доби, план і
рух камери, настрій, фактури.

> «потрібен промт для відео, де дівчина йде красивим містом»
> → сцена з ранковим світлом, бруківкою, повільним рухом камери слідом,
> конкретними деталями одягу й настрою.

Промти для відео та зображень пишуться англійською — генеративні моделі
розуміють її значно краще. Змінити це можна командою `/prompt`
(наприклад: `/prompt пиши промти українською`).

Названий вами задум — герой, дія, місце — лишається недоторканим: модель
додає деталі, але не підміняє суть.

Налаштування зберігаються окремо для кожного користувача в Cloudflare KV.
Поля, яких ви не змінювали, підхоплюють значення з `wrangler.toml` — тобто
нову типову модель достатньо прописати в конфізі й зробити `deploy`.

## Обмеження цього варіанта

Порівняно з Python-версією в корені репозиторію:

- **Розпізнавання лише через Whisper** (Groq чи OpenAI). Аудіо-моделі
  OpenRouter недоступні: вони приймають mp3 і wav, Telegram віддає ogg, а
  перекодувати нема чим — ffmpeg у Workers не запускається. Вибір
  **текстової** моделі через OpenRouter лишається повним.
- **Довгі записи не ріжуться на шматки** — з тієї ж причини. На практиці це
  майже не заважає: Telegram і так не дає ботам завантажувати файли більші
  за 20 МБ, а голосове в opus важить близько 1 МБ за 10 хвилин.
- **Фото й нагадування є лише тут.** Python-версія їх не має: нагадування
  потребують планувальника, якого в ній немає, і переносити його туди сенсу
  мало, поки бот працює на Cloudflare.
- **Дедуплікація не абсолютна.** Якщо обробка затягнеться, Telegram надішле
  оновлення повторно; від подвійної обробки захищає позначка в KV, але KV
  синхронізується між регіонами не миттєво, тож рідкісний подвійний запуск
  теоретично можливий.

## Обслуговування

Подивитись, що відбувається в реальному часі:

```bash
npx wrangler tail
```

Оновити код після змін — знову `npx wrangler deploy`.

Ліміти безкоштовного тарифу, у які ми вкладаємось: 100 000 запитів на добу,
10 мс процесорного часу на запит (очікування мережі не рахується), 128 МБ
пам'яті. Тривалість запиту не обмежена, поки Telegram тримає з'єднання —
саме тому обробка йде синхронно, а не через `waitUntil()`, який обірвався б
через 30 секунд.

## Розробка

```bash
npm test          # модульні тести
npm run typecheck # перевірка типів
npm run dev       # локальний запуск на workerd
```

Для локального запуску створіть файл `.dev.vars` (він у `.gitignore`):

```
TELEGRAM_BOT_TOKEN=...
OPENROUTER_API_KEY=...
GROQ_API_KEY=...
WEBHOOK_SECRET=...
ALLOWED_USER_IDS=...
```

Структура:

```
src/
├── index.ts            маршрути, перевірка секрету, дедуплікація, планувальник
├── env.ts              змінні оточення та рушії STT
├── telegram.ts         клієнт Bot API, розбір повідомлень
├── settings.ts         персональні налаштування в KV
├── prompts.ts          промпти редактора, стилі обробки
├── texts.ts            тексти інтерфейсу, розбиття довгих відповідей
├── keyboards.ts        інлайн-клавіатури
├── openrouter.ts       редагування тексту, каталог моделей
├── stt.ts              розпізнавання через Whisper
├── vision.ts           читання тексту з фото
├── reminders.ts        розбір, зберігання та вибірка нагадувань
├── timezone.ts         локальний час користувача з урахуванням переходів
├── pipeline.ts         сценарії «голосове → текст» і «фото → текст»
└── handlers/
    ├── commands.ts     обробка команд
    └── callbacks.ts    обробка натискань на кнопки
```
