# Voice2Text UA — Telegram-бот розшифровки голосових

Надсилаєш боту голосове повідомлення — отримуєш охайний письмовий текст:
без «е-е», повторів, обмовок і слів-паразитів, із пунктуацією та абзацами.

Розрахований на **українську мову й суржик**, англійські назви та терміни
(React, Kubernetes, deadline) лишаються латиницею з правильним написанням.

Працює у два кроки:

1. **Розпізнавання (STT)** — Whisper через OpenAI чи Groq, або аудіо-модель
   через OpenRouter. Рушій перемикається прямо в боті.
2. **Редагування** — будь-яка текстова модель OpenRouter причісує транскрипт
   за жорстким набором правил.

---

## Дві версії: оберіть одну

| | [`worker/`](worker/) — Cloudflare Workers | цей каталог — Python + Docker |
| --- | --- | --- |
| **Де працює** | на Cloudflare, сервер не потрібен | ваш VPS або комп'ютер |
| **Скільки коштує** | безкоштовно й безстроково | від $0 (Oracle Free) до ~$5/міс |
| **Обслуговування** | ніякого | оновлення системи, перезапуски |
| **Розпізнавання** | лише Whisper (Groq / OpenAI) | Whisper **або** аудіо-моделі OpenRouter |
| **Довгі записи** | одним шматком, до 20 МБ | ріже по паузах, без обмежень |

**Якщо ви не впевнені — беріть [`worker/`](worker/README.md).** Розгортання
займає хвилин десять, після чого до інфраструктури можна не повертатись.
Вибір текстової моделі через OpenRouter там повний, а втрачаються лише
можливості, що впираються в ffmpeg.

Python-версія нижче потрібна, якщо ви хочете розпізнавати аудіо-моделями
OpenRouter або регулярно надиктовуєте дуже довгі записи.

## Швидкий старт (Python + Docker)

```bash
git clone https://github.com/karrelia/Text.git
cd Text
cp .env.example .env
# впиши TELEGRAM_BOT_TOKEN, OPENROUTER_API_KEY і ключ для STT
docker compose up -d --build
```

Далі напиши боту `/start`. Якщо `ALLOWED_USER_IDS` порожній, бот у відповідь
покаже твій Telegram ID — впиши його в `.env` і перезапусти:

```bash
docker compose restart
```

### Без Docker

Потрібен Python 3.11+ і `ffmpeg` у `PATH`.

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # заповнити
python -m bot
```

## Ключі, які треба отримати

| Змінна | Де взяти | Обов'язково |
| --- | --- | --- |
| `TELEGRAM_BOT_TOKEN` | [@BotFather](https://t.me/BotFather) | так |
| `OPENROUTER_API_KEY` | [openrouter.ai/keys](https://openrouter.ai/keys) | так |
| `OPENAI_API_KEY` | [platform.openai.com](https://platform.openai.com/api-keys) | якщо STT = OpenAI |
| `GROQ_API_KEY` | [console.groq.com](https://console.groq.com/keys) | якщо STT = Groq |

`ALLOWED_USER_IDS` — список Telegram ID через кому. Бот приватний: усім іншим
він відповідає відмовою й показує їхній ID.

## Який рушій розпізнавання обрати

| Рушій | Плюси | Мінуси |
| --- | --- | --- |
| **Whisper (Groq)** | найдешевший і найшвидший, `whisper-large-v3` добре тримає українську | окремий ключ, ліміт 25 МБ на файл |
| **Whisper (OpenAI)** | стабільна якість, приймає ogg напряму без конвертації | дорожчий за Groq |
| **OpenRouter (аудіо-модель)** | один ключ і один рахунок на все; Gemini добре чує суржик і контекст | потрібен ffmpeg (конвертація в mp3), вибір обмежений моделями з audio input |

Порада: почни з Groq — за ті самі гроші розпізнає значно більше. Якщо не
хочеться заводити другий ключ, став OpenRouter.

Рушій змінюється командою `/stt` у самому боті, без перезапуску.

## Команди бота

| Команда | Що робить |
| --- | --- |
| `/settings` | показує поточну конфігурацію |
| `/model` | модель редагування тексту — пресети, пошук (`/model claude`) або точний id (`/model anthropic/claude-sonnet-4.5`) |
| `/style` | стиль обробки: Чистовик / Дослівно / Діловий / Без обробки |
| `/stt` | рушій розпізнавання |
| `/sttmodel` | аудіо-модель, коли рушій — OpenRouter |
| `/glossary` | імена, назви й терміни, які треба писати правильно |
| `/prompt` | власна інструкція на додачу до стандартних правил |
| `/reset` | скинути все до типових значень |

Налаштування зберігаються **окремо для кожного користувача** в SQLite
(`data/bot.db`). Поля, яких користувач не змінював, підхоплюють значення
з `.env` — тобто нову типову модель досить прописати в конфізі.

### Стилі обробки

- **Чистовик** (типовий) — літературна українська: суржик і кальки
  замінюються правильними відповідниками, граматика виправляється.
- **Дослівно** — авторська лексика й суржик зберігаються, чистяться лише
  запинки, повтори та обмовки.
- **Діловий** — нейтрально-офіційний тон, придатний для листа чи документа.
- **Без обробки** — сирий транскрипт без звернення до LLM (швидко й дешево).

### Словник

Найбільший приріст точності дає `/glossary`. Терміни звідти йдуть **і** в
розпізнавання (як prompt для Whisper), **і** в редагування:

```
/glossary Кириленко, ТОВ «Миргородводоканал», Kubernetes, ClickHouse
```

## Що вміє з довгими записами

- Приймає голосові, аудіофайли (mp3, m4a, ogg, wav…) і відеокружечки.
- Записи довші за `CHUNK_TARGET_SECONDS` (типово 10 хв) ріжуться **по паузах
  у мовленні**, а не посеред слова: `ffmpeg silencedetect` шукає тишу у вікні
  [50%, 100%] від цільової довжини шматка.
- Шматки розпізнаються послідовно й склеюються через маркер `[...]`, який
  редактор прибирає, з'єднуючи речення природно.
- Ліміт Telegram — 20 МБ на файл, який бот може завантажити. Це приблизно
  4 години голосового повідомлення (opus), але лише кілька хвилин WAV.
- Відповідь довша за 4096 символів ріжеться на кілька повідомлень по межах
  абзаців і речень.

## Розгортання через webhook

Типово бот працює на long polling — публічний домен не потрібен. Якщо треба
webhook:

```env
MODE=webhook
WEBHOOK_BASE_URL=https://bot.example.com
WEBHOOK_SECRET=довгий-випадковий-рядок
```

Бот слухає `WEBAPP_HOST:WEBAPP_PORT`; TLS і проксі — на боці nginx/Caddy.

Структура:

```
bot/
├── __main__.py          точка входу, polling/webhook
├── config.py            налаштування з .env
├── deps.py              спільні залежності хендлерів

├── texts.py             тексти інтерфейсу
├── keyboards.py         інлайн-клавіатури
├── middlewares.py       whitelist доступу
├── handlers/
│   ├── common.py        /start, /help, /settings, /reset
│   ├── settings.py      вибір моделей, рушія, стилю, словник
│   └── voice.py         основний сценарій обробки аудіо
└── services/
    ├── openrouter.py    клієнт OpenRouter + каталог моделей
    ├── audio.py         ffmpeg: конвертація, нарізка по паузах
    ├── cleanup.py       редагування транскрипту, підготовка відповіді
    └── stt/             рушії розпізнавання
        ├── whisper_api.py       OpenAI-сумісний /audio/transcriptions
        └── openrouter_audio.py  аудіо-моделі OpenRouter
```

### Про безпеку промпту

Транскрипт передається редактору в тегах `<transcript>`, а системний промпт
прямо каже, що це **дані, а не інструкції**. Тож фраза «забудь усе попереднє»,
сказана вголос, потрапить у текст, а не змінить поведінку бота.
